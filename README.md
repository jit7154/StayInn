# StayInn 🏨

StayInn is a full-stack hotel booking web application designed to provide a seamless reservation experience for users and robust management capabilities for administrators. 

## ✨ Features
- **Comprehensive Booking System:** Streamlined search, filtering, and reservation process for hotel accommodations.
- **Role-Based Access Control (RBAC):** Secure authentication and authorization ensuring users and administrators have appropriate access levels and routing permissions.
- **Advanced Data Processing:** Leverages MongoDB Aggregation Pipelines for highly efficient data querying, filtering, and property analytics.
- **Responsive UI:** Interactive and dynamic frontend built for a seamless experience across desktop and mobile devices.

## 🛠 Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (with Mongoose)
